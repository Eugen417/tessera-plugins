# Weather Informer

A Tessera plugin that shows current weather combining data from a Bluetooth sensor and a Zigbee sensor for accuracy.

## Set up
1. Install this plugin in the Tessera app.
2. Add the "Weather Informer" tile to your screen.
3. In the tile settings, enter your Bluetooth sensor ID (e.g. `sensor.bthome_sensor_9782_temperature`).
4. Enter your Zigbee sensor ID (e.g. `sensor.shelly_ws90_temperature`).
5. Choose whether to average the values or use only one of them.
6. The screen will display the calculated temperature!
