# Погодный Информер

Плагин для Tessera, который отображает текущую погоду, объединяя данные с Bluetooth-датчика и Zigbee-датчика для повышения точности.

## Настройка
1. Установите этот плагин через приложение Tessera.
2. Перейдите в редактор экранов и добавьте плитку «Погода» (Weather Informer) на ваш экран.
3. В настройках добавленной плитки введите ID вашего Bluetooth-датчика (например, `sensor.bthome_sensor_9782_temperature`).
4. Введите ID вашего Zigbee-датчика (например, `sensor.shelly_ws90_temperature`).
5. Выберите режим работы: усреднять значения или использовать только один конкретный датчик.
6. Сохраните настройки. Теперь экран будет отображать актуальную вычисленную температуру!
